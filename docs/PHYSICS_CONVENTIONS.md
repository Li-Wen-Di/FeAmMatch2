# 物理约定与验证边界

采用 Minkowski 标量作用量，标准动能正号、势能负号；d=4-2 epsilon，MSbar 公共测度，圈计数 h 对应 1/(16 Pi^2)。用户 Green 算符的阶乘和符号由实际局域顶点求导处理，不依靠系数名称。

UV 树级自由核必须规范、对角且在原点驻定，非导数势可重整化。两圈单一重阈值；当前局域极点提取需非零参考轻质量。保留普通重场桥，排除轻场桥，处理对象为离壳 1LPI。

## 一/两圈组装

P(C)/epsilon 表示 Green 系数的一圈作用量反项。EFT 1PI 圈发散为 -P(C0)/epsilon，显式一次符号化插入的发散为 -DP(C0)[delta C]/epsilon。用局域作用量生成带反项符号的树振幅后再进入式（160）。

一圈 UV hard 结果加上 UV 反项的经典重场消去贡献后，减去 P(C0)/epsilon 并投影，保存 C1,d=F+epsilon E。UV 反项由完整 UV 理论确定，不能只取 hard 中所有极点。

式（160）的三项保存在 `eq160-contributions.wl`。按通道以两圈 UV 全硬振幅加上一圈 UV 反项插入硬振幅，减去 DP(C0)[C1,d]/epsilon。有限位移 -DP(C0)[E] 必须保留。在代入 C1,d 后再截断低能权重，计入会被加性质量阈值提升的树级维八算符与多重插入。论文式（154）的一次维六插入公式适用于该截断下的一圈极点。

程序另外计算式（159）的 UV 树级两圈反项及一圈反项乘积的重场消去贡献，要求它们为纯极点。将其加到式（160）的三项组合后取局域极点，得到匹配轨迹上的 EFT 反项。有限 Green 系数取 epsilon 零次项。

整体极点推断不是独立的 EFT 两圈重整化函数；删除推断的极点后零余项只是构造关系。验证另比较冻结参考反项、双极点递推 Q=DP[P]/2、RG 与有限系数。此递推限于本包标量作用量坐标及统一 mu 权重，不能直接泛化到 evanescent 或任意重参数化方案。

## 截断与转换

轻质量/外动量权重为 1，重阈值为 0；额外参数权重由请求提供。UV 一圈匹配比最终目标多保留两单位辅助工作权重；UV 一圈 CT 插入已经为总两圈阶，采用最终 Taylor 预算。反项的 1/epsilon 要求相关一圈积分到 O(epsilon)。

当前物理结果为有序形式维六转换。树诱导维八辅助结构由作用量生成，属于已验证工作闭合，不是一般高维圈闭合、完整 UV-fixed joint 投影或任意模型完备性证明。先保存截断前转换输入，再分别截断原场 Green 和物理系数。场转换必须保留低圈乘积，包括二阶非交换动能矩阵项和维五场变换平方。

## 优化条件

单圈 n 条标量传播子、分子最大圈秩 R，只在 4+R-2n<0 时丢弃局域 UV 极点为零的项。此判断限于有质量参考核和局域极点，不能用于删除有限 hard 振幅。未知界和显式 epsilon 依赖保留。

重源统一前因子的最小轻权重超过通道预算、其他顶点均非负权、重质量零权时，可跳过整个 hard 分支。未知或负界继续生成。零外动量提前代入只影响外动量，参考质量和量子场导数仍完整保留。
